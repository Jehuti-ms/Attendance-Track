Instructions

  1. Open your Google Sheet
  2. Go to Extensions → Apps Script
  3. Copy and paste the backend code
  4. Click Deploy → New Deployment
  5. Select type: Web app
  6. Execute as: Me
  7. Who has access: Anyone
  8. Click Deploy and copy the Web App URL
  9. Paste the URL above and click Save Settings
  10. Click Initialize Sheets to create the sheets with sample data
